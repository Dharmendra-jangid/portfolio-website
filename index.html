Telegram blog bot with n8n, Laravel, and Gemini

A blog is written in Telegram. n8n runs the workflow, Google Gemini drafts the post, and the draft is sent to the Laravel site. It goes live only after it is approved.

  1. Ask the Telegram bot for a blog. n8n calls the Google Gemini API and prepares the draft.
  2. The draft lands in the writer panel, marked for a check.
  3. Approve it in the panel, or reply PUBLISH in Telegram, and the post is published on the website.
  4. If the text is wrong, reject it or edit it before it goes live.
